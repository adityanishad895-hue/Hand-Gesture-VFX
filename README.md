# Real-Time Hand Gesture VFX System 🖐️✨

A real-time computer vision application that creates glowing neon visual effects and interactive magic around hand movements using your webcam.

Powered by **OpenCV**, **MediaPipe**, and **NumPy**.

---

## ✨ Features

- **Neon Hand Skeleton**: Vivid neon glow tracking each finger and joint in real-time.
- **Energy Aura**: Subtle energy aura radiating from detected hands.
- **Energy Beam**: Connect fingertip beams and dynamic electrical arcs.
- **Magic Shield**: Rotating arcane magic circle on your palm.
- **Fingertip Join Burst**: Glowing burst effects when fingertips touch.
- **Cinematic Post-Processing**: Bloom and cinematic tone mapping.

---

## 🚀 Quick Start

### 1. Prerequisites
- Python 3.8+
- A working webcam

### 2. Installation
Clone the repository and install the required dependencies:

```bash
git clone https://github.com/<your-username>/Hand-gesture-vfx.git
cd Hand-gesture-vfx
pip install -r requirements.txt
```

### 3. Run the Application
```bash
python main.py
```

## 🎮 Controls

| Key | Action |
|:---:|:---|
| `a` | Toggle Hand Aura (ON / OFF) |
| `b` | Toggle Energy Beam (ON / OFF) |
| `s` | Toggle Magic Shield (ON / OFF) |
| `q` | Quit Application |
